# CRM Plus Store

Site institucional estático em HTML, CSS e JavaScript. Publicação na Vercel a partir da branch main.

## Desenvolvimento

Execute `python3 -m http.server 8080` na raiz e abra http://localhost:8080.

Edite textos e projetos em `index.html`, identidade visual em `styles.css` e navegação em `script.js`. Assets e fontes locais em `assets/`.

Sem banco de dados, autenticação ou dependências de build. Contato via WhatsApp e e-mail. Fontes distribuídas sob SIL OFL; licenças em assets/FONT-LICENSES.txt.
